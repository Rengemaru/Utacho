## 0. バージョン

**本リリース（1.2.1）**
- **versionName：`1.2.1`**（`app.json` `expo.version`・1.2.0 → 1.2.1 に更新）
  - ⚠️ 1.2.0 のまま配布するとユーザーから見てバージョンが変わらないため、必ず **1.2.1** へ上げる。
- **versionCode：`8`**（`app.json` で設定）
  - ⚠️ 現行の最新 versionCode は **7**。次ビルドは **必ず 8 以上**でないとアップロードできない。
  - `eas.json` は `autoIncrement: true` のため、EAS ビルド時にはリモート最大値 +1（＝8）へ自動設定される。`app.json` の `8` はそれに合わせた明示値。

## 1. このリリースに含まれる変更（1.2.0 → 1.2.1）

すべて不具合修正。マイルストーン `v1.2.1 不具合修正リリース`。

| PR | 変更 | 種別 | Issue |
|---|---|---|---|
| #104 | 曲編集画面で、設定済みのタブ（カテゴリ）が外れて表示される不具合を修正 | 不具合修正 | #105 (A) |
| #111 | 曲詳細画面で、編集・保存後も編集前の内容が表示される不具合を修正（フォーカス時に再読込） | 不具合修正 | #105 (B) |
| #112 | 「今日のセットリスト」の曲数（バッジ/タブ）と実際のリスト件数が一致しない不具合を修正（削除済み曲IDを掃除） | 不具合修正 | #109 |

### 原因と対応の要点
- **#104 タブ外れ**：編集時にタブ一覧ロード前の絞り込み effect が、曲タブ復元 effect と同一バッチで走り、古い空配列で全タブを除去していた。ロード完了までは絞り込まないようガード。
- **#111 編集後の古い表示**：`useSongDetail` がマウント時のみ取得で、詳細画面に `useFocusEffect` が無かった。フォーカス時に `reload()` するよう追加。
- **#112 セットリスト曲数不一致**：削除された曲IDが settings に残り、バッジ/タブ（`setlistIds.length`）とリスト（`getSongsByIds`）で食い違っていた。`getSetlistSongIds` の読み取り時に存在しない曲IDを除去。

## 2. リリースノート（テスター／ストア向けドラフト）

> いくつかの不具合を修正しました。

- 曲を編集すると、設定していたタブ（カテゴリ）が外れてしまう問題を修正しました。
- 曲を編集して保存した直後、詳細画面に古い内容が残って見える問題を修正しました。
- 「今日のセットリスト」に入れた曲を削除したとき、曲数の表示が実際と合わない問題を修正しました。

## 4. ビルドと提出（オーナー実施）

```bash
# AAB ビルド（Google Play 必須形式）
eas build --platform android --profile production

# クローズドテストへ提出（eas.json: track=internal）
eas submit --platform android --profile production
```

- ビルド前に `app.json` の `expo.version` が **1.2.1**、`versionCode` が **8**（≥8）になっていることを確認する。
- `versionCode` は `autoIncrement: true` によりリモート最大値（現 7）+1 = **8** へ自動設定される。
- クローズドテストのトラックは停止しない（停止すると14日カウントがリセット）。

## 5. 公開（本番トラックへ）

- クローズドテストで実機確認が完了したら、`eas.json` の `submit.production.android.track` を `internal` → `production` に変更して提出する（または Google Play Console でトラックを昇格）。
