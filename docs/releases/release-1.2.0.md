# 1.2.0 リリース手順書

> 1.1.0（検索フロー再設計）クローズドテスト配布後に追加した機能をまとめて配布するリリース。
> 実機テスト・EAS ビルド・ストア提出はオーナーが実施する。
> 前リリースの記録：`docs/releases/release-1.1.0.md`

## 0. バージョン

**Google Play 現状（2026-10-07 時点・クローズドテスト Alpha）**
- リリース名：**1.1.0**／App Bundle **versionCode 6**（有効・完全公開 100%）
- 過去バンドル：1.0.0（versionCode 3=非アクティブ、versionCode 2=有効）

**本リリース（1.2.0）**
- **versionName：`1.2.0`**（`app.json` `expo.version`・1.1.0 → 1.2.0 に更新）
  - ⚠️ 1.1.0 のまま配布すると、ユーザーから見てバージョンが変わらずアップデートが降ってくる状態になるため、必ず **1.2.0** へ上げる。
- **versionCode：`7`**（`app.json` で設定）
  - ⚠️ 現行の最新 versionCode は **6**。次ビルドは **必ず 7 以上**でないとアップロードできない。
  - `eas.json` は `autoIncrement: true` のため、EAS ビルド時にはリモート最大値 +1（＝7）へ自動設定される。`app.json` の `7` はそれに合わせた明示値（autoIncrement を切った場合の保険）。

## 2. リリースノート（テスター／ストア向けドラフト）

> 検索まわりの使い勝手とタブレット表示を改善しました。

- **検索履歴**：曲の追加検索と、持ち歌リストの検索で、過去に検索したキーワードを候補として表示（検索欄をタップすると履歴がドロップダウンで出ます）。不要な履歴は1件ずつ、またはまとめて削除できます。
- **タブレット対応**：大きい画面で曲一覧を2列表示にし、ボタンも押しやすく調整しました。
- **操作性の改善**：ボタンのタップ範囲を広げ、曲カードの長押しや履歴のタップからも編集・削除できるようにしました（スワイプが分からなくても操作できます）。
- **お問い合わせ**：アプリ内からお問い合わせフォームを開けるようにしました。
- **不具合修正**：文字入力時に画面がガタつく問題を修正しました。

## 4. ビルドと提出（オーナー実施）

```bash
# AAB ビルド（Google Play 必須形式）
eas build --platform android --profile production

# クローズドテストへ提出（eas.json: track=internal）
eas submit --platform android --profile production
```

- ビルド前に `app.json` の `expo.version` が **1.2.0**、`versionCode` が **7**（≥7）になっていることを確認する。
- `versionCode` は `autoIncrement: true` によりリモート最大値（現 6）+1 = **7** へ自動設定される。
- クローズドテストのトラックは停止しない（停止すると14日カウントがリセット）。

## 5. 公開（本番トラックへ）

- クローズドテストで実機確認が完了したら、`eas.json` の `submit.production.android.track` を `internal` → `production` に変更して提出する（または Google Play Console でトラックを昇格）。
