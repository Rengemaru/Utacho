標準 Alert を置き換えるアプリ独自モーダルの設計案。
2択・破壊的・複数選択肢（説明付き）・通知の各パターンを、アプリのデザイントークンで統一する。

B. 複数選択肢（3つ以上・説明つき）今回の主目的

Alert では難しかった「3択以上」「各選択肢に説明文」を縦リストで表示。各行にアイコン＋ラベル＋説明。破壊的な選択は赤。最下部にキャンセル。

選択肢が多い/親指で押しやすい場面はボトムシートも可。既存の並べ替え・セットリストと統一感がある。どちらを基本にするか要相談。
実装方針（案）
・ルートに ConfirmProvider を置き、どこからでも await confirm({ title, message, icon?, options:[...] }) で呼ぶ。
・options は 任意個数。各 { label, description?, icon?, style:'default'|'primary'|'danger' }。2個なら A の横並びボタン、3個以上や説明つきなら B の縦リストに自動切替。
・戻り値は押された選択肢（またはキャンセル）。Android 物理戻るボタン＝キャンセル扱い。
・中央カード（A/B-1,B-2）を基本、長押しメニューなどアクション選択はボトムシート（B-3）…の二本立てにするか、片方に寄せるかは確認したい点。
