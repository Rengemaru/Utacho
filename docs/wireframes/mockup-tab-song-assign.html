🧭 操作フロー

  1. 曲一覧上部のタブを長押し → メニュー表示
  2. 「タブの詳細設定」を開く（名前変更／削除／対応曲を変更／所属曲一覧）
  3. 「対応曲を変更」でチェックボックス付きの曲一覧（検索・並べ替え対応）
  4. チェックを付け外し → 「設定する」でそのタブの所属曲を一括反映
