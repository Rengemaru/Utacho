# 1.0.2 仕様書：Android 16（API 36）対応

> versionName：1.0.2 / ターゲットAPI：35 → **36** / 前提：1.0.1 の配布後にリリース（D1 の調査は並行可）
> 索引：[README.md](./README.md)

> **状態（2026-10-07 追記）**：**1.1.0 に統合済み**（単独の 1.0.2 リリースは行わない。`release-1.1.0.md` 参照）。
> targetSdk 36 / compileSdk 36 は `app.json` の `expo-build-properties`（`targetSdkVersion: 36` / `compileSdkVersion: 36`）で固定済み。
> 本ファイルは計画時点の記録として残す。

## 1. 背景

2026-08-31 以降、Google Play では新規アプリ・アプリ更新ともに Android 16（API 36）以上をターゲットにしないと提出できない。歌帳の現行版は API 35 で、延長を申請済み。**延長の期限は 2026-11-01**。それ以降は 1.1.0 も緊急の不具合修正も API 36 でないと配布できない。

このリリースは **API 36 への対応だけ**を行い、機能は一切変えない。新機能と混ぜないことで、不具合が出たときに原因を API 36 の挙動変更に絞り込めるようにする。

## 2. スコープ

### やること
- targetSdkVersion を 36 にする（必要なら compileSdkVersion・Expo SDK・依存パッケージも更新）
- API 36 の挙動変更によって崩れる箇所の修正
- 全画面の回帰テスト（既存機能が壊れていないかの確認）

### やらないこと
- 機能追加・UI変更
- DB スキーマの変更

## 3. API 36 で影響しうる変更（⚠️ 確実ではない。D1・D4 で実際に確認する）

| 変更 | 歌帳で影響しうる箇所 |
|---|---|
| 画面端までの描画（edge-to-edge）の強制。アプリ側で無効にできなくなる | ステータスバー・ナビゲーションバーとヘッダー、下部ナビ、下部固定ボタン（「点数を記録する」「曲を追加する」）、ボトムシートの重なり |
| 戻る操作が「予測型戻る」方式に移行し、従来の戻るボタンイベントの扱いが変わる | 各画面の戻る操作、ボトムシート（点数入力 03・点数編集 02b）を戻る操作で閉じる挙動、初回セットアップ（07）の戻る操作無効化 |
| キーボード表示時のレイアウト | 曲登録フォーム、点数入力のボトムシート |

## 4. タスク

### D1 調査（調査のみ・1.5h）
- 現在の Expo SDK・React Native のバージョン
- targetSdkVersion・compileSdkVersion の指定箇所（app.json / app.config / expo-build-properties）
- API 36 にするために必要な変更が「設定の変更だけ」か「Expo SDK の更新が必要」かの判断材料
- `BackHandler` など戻る操作を扱っている箇所の一覧

※ A1（1.0.1 の調査）で同じ項目を調べた場合は、その結果を使ってよい。

**受け入れ条件**：必要な変更の範囲と、D2 の工数見込みが報告されている。SDK 更新が必要な場合は、2時間以内のタスクに分割した追加計画がある。

### D2 設定変更・依存更新（2h〜。⚠️ SDK 更新が必要なら追加）
**受け入れ条件**：targetSdkVersion 36 で EAS Build が成功する。

### D3 挙動変更への対応（2h）
3章の表の箇所を確認し、崩れていれば直す。

**受け入れ条件**：Android 16 の端末（またはエミュレータ）で、ヘッダー・下部ナビ・下部固定ボタンがシステムのバーと重ならない。戻る操作で各画面・ボトムシートが v1.0.1 と同じ挙動になる。

### D4 Android 16 での回帰テスト（2h）
**受け入れ条件**：Android 16 と、それより古い Android の各1台（実機またはエミュレータ）で次をすべて確認した。
- [ ] 初回セットアップ（07）：機種を選んで開始できる。戻る操作で抜けられない
- [ ] 曲の登録・編集・削除（04・01b）、重複警告
- [ ] 1.0.1 で直した候補リストのスクロール・選択
- [ ] 点数の記録・編集・削除（03・02b・02）、機種の選択とセッション記憶
- [ ] グラフ表示（02）
- [ ] タブの追加・編集・削除（05）
- [ ] バックアップの書き出し・読み込み
- [ ] ヘルプ画面の表示
- [ ] 各画面の戻る操作

### D5 修正バッファ（2h）
D4 で見つかった不具合を直す。

[README.md の共通ルール](./README.md#配布各リリース共通の-c-タスク) に従う。versionName は **1.0.2**。
